4. Descripción del sistema
Aplicación web diseñada para simplificar el préstamo de libros en bibliotecas. Permite a los usuarios registrar pedidos tanto para retiro a domicilio como para lectura dentro de la institución de forma ágil y ordenada.




5. Pantallas desarrolladas
-Solicitar Prestamo (solicitar-prestamo.html): Formulario para registrar la reserva de un ejemplar.




-Confirmacion (confirmacion.html): Vista que emite un comprobante digital al concretar la solicitud.


-Mis Prestamos (mis-prestamos.html): Seccion para revisar los libros solicitados.



6. Breve explicacion
-Solicitar Prestamo: Cuenta con campos de entrada (input) y menus desplegables (select) validados mediante atributos HTML (required) para asegurar que el socio ingrese correctamente su identificacion y elija un libro disponible, recordando que existe un limite maximo de 3 prestamos simultaneos.


-Confirmacion: Visualiza un bloque con diseno de comprobante destacado (comprobante) que detalla de forma clara los datos de la reserva generada, ofreciendo accesos directos para volver al inicio o consultar los prestamos.


-Mis Prestamos: Permite listar mediante tablas de control el historial o estado de los libros solicitados por el socio.



7. Futuras aplicaciones
-Sistema de notificaciones: Envío de alertas automáticas por correo electrónico cuando un préstamo esté próximo a vencer.
-Búsqueda avanzada de libros: Implementación de filtros de búsqueda por género, autor o año de publicación para facilitar la localización de ejemplares.
-Módulo de penalizaciones: Registro y gestión de suspensiones o multas para los socios que devuelvan los libros fuera de término.
